The mechanism

Three steps. One clear outcome.

Softmax does not average the values itself. It creates the weights.

  1. 1

    Score each item

    Logits express relative importance. Higher means more influence.

    1.0  2.0  3.0
  2. 2

    Normalize with softmax

    Exponentiate the scores, then divide each by their total.

  3. 3

    Blend the values

    Multiply every value by its weight, then add the contributions.

    0.90 + 4.89 + 19.96 = 25.75

Use it

The whole idea in five lines.

The browser demo mirrors the same numerically stable Python implementation.

example.py 
values = np.array([10.0, 20.0, 30.0])
logits = np.array([1.0, 2.0, 3.0])
weights = softmax(logits)
weighted_average = np.sum(weights * values)
print(weighted_average)  # 25.75

That’s it. For production scientific code, use scipy.special.softmax.
